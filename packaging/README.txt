TELEINK — unofficial Telegram client for PocketBook

EN  Copy everything from the archive into the "applications" folder of the reader.
    Open Teleink in Applications.
    API keys, if asked: my.telegram.org → API development tools
    (or put them in teleink-api.txt in the reader's root: line 1 api_id, line 2 api_hash).
    Downloads: Downloads/Teleink   Logs: system/teleink

UA  Скопіюйте все з архіву в папку «applications» на рідері.
    Відкрийте Teleink у «Програмах».
    Ключі API, якщо попросить: my.telegram.org → API development tools
    (або у teleink-api.txt у корені рідера: рядок 1 api_id, рядок 2 api_hash).
    Файли: Downloads/Teleink   Журнали: system/teleink

RU  Скопируйте всё из архива в папку «applications» на ридере.
    Откройте Teleink в «Приложениях».
    Ключи API, если попросит: my.telegram.org → API development tools
    (или в teleink-api.txt в корне ридера: строка 1 api_id, строка 2 api_hash).
    Файлы: Downloads/Teleink   Журналы: system/teleink

Uses the Telegram API (TDLib). Not affiliated with Telegram.
